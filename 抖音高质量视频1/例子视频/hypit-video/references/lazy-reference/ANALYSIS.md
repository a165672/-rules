# 参考视频整体解读

源文件：[`../../../reference/参考视频.mp4`](../../../reference/参考视频.mp4)（1280×720，30fps，110.2s，H.264 + AAC）。
1 秒一帧的缩略图：`../../../reference/frames/g_NNN.jpg`（第 NNN−1 秒）。

## 它是什么
一条无旁白的“知识类动态排版”横屏视频，主题是拖延的神经科学（“你不是懒，你是陷入了回避循环”）。
全片只有文字、细线、发光圆点和几何图形，没有实拍、没有配音；信息全部靠逐字出现的标题和小字说明，
配一段持续推进的电子配乐（≈129 BPM）。

## 为什么好看、留得住人
1. **钩子在第 0 帧**：满屏横向漂移的“借口”念头墙 + 中央大字随重拍切换，1.5s 一记白闪进入主题句“你不是~~懒~~。”。
   先否定观众的自我评价，再给一个新概念（回避循环），制造“原来如此”的期待。
2. **一个概念一个画面**：每个镜头只立一件事——一个循环图、两个对抗的光点、一张清单、一个被划掉的词、一个大数字。
3. **问题—机制—伪装—真相—解法** 的五章结构，章节标记（■ 01 名称）和底部带刻度的进度条让人知道“还剩多少”。
4. **颜色即情绪**：问题章节暗红辉光，红色只用在“坏东西”（焦虑、警报、0%）；解法章节整体转为荧光绿。
5. **全部卡点**：出字、划线、计数、闪屏都落在配乐的拍点/小节线上；章节切换对齐配乐段落（16.5 / 35.5 / 51.6 / 64.5 / 83.6s）。
6. **结尾给行动**：圆环闭合→爆散→绿色播放键，“现在，关掉这个视频，去做那件事的前 10 分钟”，把情绪落到一个极小的动作上。

## 反复出现的视觉系统
- 背景：近黑底 + 大面积径向暗角 + 随章节变化的低饱和辉光；极轻的胶片颗粒。
- 文字：标题为粗宋体（思源宋体 Heavy 一类），暖白；说明为灰色黑体小字。入场 = 逐字由模糊变清晰并轻微上移；出场 = 整体模糊淡出。
- 强调：红色（带外发光）用于问题与警报，白色细线/红线“划掉”旧认知，荧光绿只出现在解法里。
- 版式元件：圆角描边胶囊标签、勾选框清单、细进度条、计数器、计时环。
- 全局 chrome：左上英文大字距标签、右上中文栏目名、顶部居中章节标记、底部章节进度条。

## 声音
纯配乐，无人声（频谱为稳定的和声线条，无语音共振峰）。配乐每 60s 循环一次，0–15s、15.5–60s、60–75s、75–110s 为四个段落，
段落交界处有短暂的能量下沉。画面的章节切换都落在这些段落交界附近。
